# PalmerPenguins-DataAnalysis
Proyecto desarrollado en KNIME Analytics Platform para el análisis y modelado de datos del conjunto **Palmer Penguins**.

Incluye:
- Limpieza y preprocesamiento de datos.
- Análisis exploratorio (EDA).
- Clustering con K-Means.
- Modelos de clasificación y regresión.
- Reporte final en PDF.

## Archivos
- `workflow.knime` → Flujo de trabajo principal de KNIME.  
- `penguins(mod).csv` → Dataset utilizado.  
- `workflow.svg` → Vista visual del flujo.  
- `Reporte_Pinguinos.pdf` → Informe del proyecto.
